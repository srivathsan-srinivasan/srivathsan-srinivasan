# Infinite Space Scroll (Portfolio)

Static portfolio site.

## Files
- `index.html` – landing page
- `experience.html` – experience timeline (expand this with your roles)
- `projects.html` – projects page scaffold
- `assets/css/styles.css` – shared styles
- `assets/js/main.js` – three.js background + section reveal
- `scripts/vendor.sh` – optional: download vendor JS for offline use

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Optional: download vendor JS (offline)
Run:
`bash scripts/vendor.sh`
